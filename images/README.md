# Screenshots Directory

This directory contains screenshots for the README.md file.

## Required Images

Please add the following screenshot files to this directory:

1. **admin-settings.png** - Screenshot of the WordPress admin settings panel
   - Navigate to: Settings → FMI Funding Calc
   - Capture the full settings page showing all configuration options

2. **calculator-form.png** - Screenshot of the calculator interface
   - Add the shortcode `[fmi_funding_calculator]` to a page
   - Capture the calculator form with results displayed

## Image Guidelines

- **Format**: PNG (preferred) or JPG
- **Resolution**: At least 1200px width for clarity
- **Content**: Ensure all text is readable
- **Privacy**: Remove any sensitive information before capturing
